## The first public release

trizy is one operating contract for every coding agent (Claude Code, Codex) and every person in a repository:
plan, build, review, gate and journal, enforced by git hooks and written in POSIX sh. It used to be agent-kit,
which was never published.

### What's inside

- **The contract:** `AGENTS.trizy.md`, the rules (delivery, reporting, testing, working) and a `CONSTRAINTS.md`
  that collects every correction, imported into `CLAUDE.md` and `AGENTS.md`.
- **Gates:** pre-commit runs the `commit` flow and requires an approved review receipt for exactly the staged
  tree; pre-push requires a run journal entry newer than the pushed commits and runs the `push` flow once per tree.
- **Flows and steps** in `.trizy/flows.tsv`: shell `run` steps and `ask` instructions, managed with
  `trizy flow` and `trizy step`.
- **The `deliver` workflow** for Claude Code: plan → packages in their own worktrees → an independent gate →
  `deliver/<slug>` → verify.
- **Skills:** `optimality-check`, `review-gate`, `retro`, plus `ponytail`, `ponytail-review` and
  `security-reviewer` (MIT, see THIRD-PARTY-NOTICES.md).
- **Tools:** worktrees from the fresh main branch, a machine-wide queue for heavy commands, a local run journal.

### New since agent-kit 0.2.3

- **Releases by tags.** `install.sh` installs the latest release and verifies its checksum, and
  `trizy upgrade [--version vX.Y.Z]` does the same for an existing install.
- **husky and other hooks paths.** `init` asks whether to replace them (recommended) or merge with them
  (`--hooks=replace|merge`). A merged hook calls trizy right after its shebang and skips the call in a checkout
  without trizy.
- **Renamed.** The command, directory, markers and variables are now `trizy`, `.trizy/`, `trizy:begin` and
  `TRIZY_*`. If you ran agent-kit: remove `.agent-kit/` and its blocks in `CLAUDE.md` and `AGENTS.md`, then run
  `trizy init`.
